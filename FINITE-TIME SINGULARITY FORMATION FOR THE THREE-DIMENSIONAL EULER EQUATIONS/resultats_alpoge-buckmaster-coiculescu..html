Résultats clés (Alpöge, Buckmaster, Coiculescu)

Théorème 1.1 (Explosion) : Il existe u₀ ∈ C∞(T³) impair, div-free, dont la solution classique explose en T* < ∞.
• Vitesse bornée : supt ‖u(t)‖L∞ < ∞
• Vorticité infinie : limt→T* |curl u(t, 0)| = ∞
Critère de Beale–Kato–Majda : Si ∫₀T ‖curl u(t)‖L∞ dt = ∞, la solution ne peut pas se prolonger lissement.
Théorème 4.2 (Inverse de Jacobi) : Sous l'hypothèse de coercivité H# ≤ Id, il existe une unique correction b(t,x) solution linéarisée, avec estimation de Hölder.
Condition de non-explosion : Si ‖ω(t)‖L∞ reste intégrable, la solution est globale. La singularité est donc portée par le point d'origine.
